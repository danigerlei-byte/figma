            1. Hug vs Fill Rule
          

          

            Parent containers (screens, modals, card grids) should always be Fill Container horizontally. Child text layers and icons should be Hug Contents or Fill depending on truncation needs.
          

          

            Parent: Fill (100%) → Child: Hug (Shrink-to-fit)
          

        


        

          

            2. Negative Spacing (Avatars)
          

          

            Never use freehand absolute positioning for overlapping avatar clusters. Instead, set Auto Layout gap to -8px or -12px, and toggle Canvas stacking to "First on top" or "Last on top".
          

          

            Gap: -10px | Stacking: First on top
          

        


        

          

            3. Min / Max Constraint Bounds
          

          

            Prevent desktop sidebars or cards from stretching infinitely. In the width dropdown, select Add Min Width (e.g. 320px) and Add Max Width (e.g. 1280px).
          

          

            Min: 320px | Max: 1200px (Clamp)
          

        


        

          

            4. Absolute Position in Auto Layout
          

          

            For notification badges, tooltips, or close buttons on card corners, use the Absolute Position toggle inside the Auto Layout frame to pin without breaking flow.
          

          

            Icon button → Pin Top-Right (Shift+A safe)
          

        

      

    


    
    

      

        

          
Enterprise Handoff Standard Operating Procedure

          
How top design systems at Airbnb, Vercel, and Stripe hand off clean files to engineering without meetings.

        


        

          
1. The 3-Tier Layer Naming Hierarchy

          

            Never leave unnamed layers like Rectangle 294 or Group 18. Use engineering component semantics:
          

          
    
            
  • Surface Level: Screen / DashboardView
    • 
            
  • Section Level: Section / AnalyticsHeader, Table / TransactionList
    • 
            
  • Atomic Level: Button / Primary / IconRight, Badge / Status / Success
    • 
          

        


        

          
2. Component Properties Over Combinatorial Variants

          

            Prior to Component Properties, a button with 3 sizes, 4 themes, 2 states, and 2 icons required 3 x 4 x 2 x 4 = 96 variants. With modern properties:
          

          
    
            
  • Boolean Property: hasIconLeft (true/false)
    • 
            
  • Instance Swap Property: iconSlot → Selection from Icon Library
    • 
            
  • Text Property: buttonLabel → "Get Started"
    • 
          

        


        

          
3. Dev Mode Ready Checklist

          

            Before marking a frame "Ready for Dev":
          

          
    
            
  • Mark status badge as Ready for Development.
    • 
            
  • Add sticky note annotations for loading states, empty states, and API error edge cases.
    • 
            
  • Ensure all icon layers are pre-configured with SVG export @ 1x and clean bounding boxes.
    •
